ENVIO RÁPIDO AO GITHUB

1. Envie TODOS os arquivos desta pasta ao seu repositório GitHub. Esta pasta possui menos de 100 arquivos.
2. No GitHub, abra o arquivo supabase-config.js e clique no ícone de lápis para editar.
3. Mantenha a linha url como está e preencha somente:
   anonKey: "COLE_A_CHAVE_ANON_PUBLICA_DO_SUPABASE"
4. Clique em Commit changes.
5. Em Settings > Pages, selecione a branch main e a pasta / (root).
6. No Supabase, em Authentication > URL Configuration, cadastre a URL publicada no GitHub Pages.

NUNCA use a chave service_role no arquivo supabase-config.js.
