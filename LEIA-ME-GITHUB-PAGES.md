# Publicação no GitHub Pages

Este ZIP foi gerado sem pasta externa. Ao extrair, os arquivos necessários já ficam na raiz: `index.html`, a pasta `assets/` e este guia.

## Como publicar

1. Crie um repositório vazio no GitHub.
2. Envie **todos os itens extraídos**, mantendo `index.html` na raiz e a pasta `assets/` completa.
3. Em **Settings → Pages**, selecione a branch em que os arquivos foram enviados e escolha a pasta raiz (`/`).
4. Salve e aguarde o endereço público ser exibido pelo GitHub.

> A pasta `assets/` é necessária para o funcionamento do aplicativo; não a exclua nem mova seus arquivos.

Os dados cadastrados pelo aplicativo continuam sendo armazenados localmente no navegador de cada dispositivo. Exporte um backup JSON antes de trocar de domínio ou navegador.
